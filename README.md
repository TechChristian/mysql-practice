# MySQL Practice 📚

repositório para meus estudos e práticas em **MySQL**, com o objetivo de documentar minha evolução e consolidar os conhecimentos na área de banco de dados.

aqui irei documentar: 

* Consultas SQL (SELECT, WHERE, ORDER BY, GROUP BY, HAVING, JOINs, entre outras);
* Resolução de exercícios e desafios;
* Soluções de problemas propostos em cursos;
* Exercícios resolvidos do LeetCode;

O principal objetivo deste repositório é registrar minha evolução em MySQL, demonstrando o aprendizado contínuo por meio de exemplos práticos, soluções comentadas e exercícios resolvidos.

À medida que avanço nos estudos, novos conteúdos e desafios serão adicionados, tornando este repositório um histórico da minha trajetória de aprendizado em SQL e bancos de dados relacionais.
